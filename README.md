# Aadhavanpl Tap

## How do I install these formulae?

`brew install aadhavanpl/tap/<formula>`

Or `brew tap aadhavanpl/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "aadhavanpl/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
